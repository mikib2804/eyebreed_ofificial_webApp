PART 1 - ONE-TIME SSH KEY SETUP
===============================

Run these commands in WINDOWS POWERSHELL.

1. Create the SSH directory and copy the original key to a stable filename.

New-Item -ItemType Directory -Path "$HOME\.ssh" -Force | Out-Null
Copy-Item "C:\misha\EasyPassVps-SSh\ssh-key-2026-11-07.key" "$HOME\.ssh\eyebreed-vps.key" -Force

2. Remove inherited permissions and allow only the current Windows user to read it.

$currentUser = [System.Security.Principal.WindowsIdentity]::GetCurrent().Name
icacls "$HOME\.ssh\eyebreed-vps.key" /inheritance:r
icacls "$HOME\.ssh\eyebreed-vps.key" /grant:r "${currentUser}:(R)"

3. Confirm that the secured key exists.

Test-Path "C:\Users\mikib\.ssh\eyebreed-vps.key"

4. Test the connection.

ssh -i "C:\Users\mikib\.ssh\eyebreed-vps.key" ubuntu@129.159.147.209

Type exit to return from Ubuntu to Windows PowerShell.

PART 5 - PRODUCTION ENVIRONMENT FILE
====================================

RECOMMENDED METHOD: securely upload the working local .env over SSH.

WINDOWS POWERSHELL

scp -i "C:\Users\mikib\.ssh\eyebreed-vps.key" "$HOME\Documents\eyebreed_ofificial_webApp\.env" ubuntu@129.159.147.209:/home/ubuntu/eyebreed.env

UBUNTU VPS

1. Install the uploaded environment file with restricted permissions.
   The docker group needs read access because Docker Compose runs as ubuntu.

sudo install -m 640 -o root -g docker /home/ubuntu/eyebreed.env /opt/eyebreed/.env

2. Remove the temporary copy. It is normal for rm to say the file does not
   exist if it was already removed.

rm -f /home/ubuntu/eyebreed.env

3. Confirm the file exists without displaying secrets.

sudo test -s /opt/eyebreed/.env && echo "Production environment file is ready"

4. Check only for known placeholder text. No output means this check passed.

sudo grep -nE 'POOLED_HOST|DIRECT_HOST|USER:PASSWORD|REPLACE' /opt/eyebreed/.env || true

IMPORTANT:
- compose.prod.yaml forces NEXT_PUBLIC_APP_URL and AUTH_URL to
  https://shop.eyebreedofficial.com.
- compose.prod.yaml forces AUTH_TRUST_HOST=true.
- The Instagram variables may remain empty; those warnings are non-fatal.

RUN THE UBUNTU ENVIRONMENT INSTALL TOGETHER

PART 6 - DNS AND FIREWALL REQUIREMENTS
======================================

DNS at IONOS:

- Keep eyebreedofficial.com pointed to Netlify.
- Add an A record named shop pointing to 129.159.147.209.
- The resulting hostname is shop.eyebreedofficial.com.

Oracle Cloud ingress rules for the instance VCN/security list:

- Stateful TCP from 0.0.0.0/0 to destination port 80.
- Stateful TCP from 0.0.0.0/0 to destination port 443.
- Optional UDP from 0.0.0.0/0 to destination port 443 for HTTP/3.
- Keep the existing SSH port 22 rule.

UBUNTU VPS - check and allow the local firewall:

sudo ufw status
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 443/udp
sudo ufw reload

WINDOWS POWERSHELL - confirm the VPS is reachable publicly:

Test-NetConnection 129.159.147.209 -Port 80
Test-NetConnection 129.159.147.209 -Port 443

Both tests should show: TcpTestSucceeded : True


PART 7 - START OR UPDATE THE PRODUCTION STACK
=============================================
